## 3. Launch checklist (30 minutes, ~₹800)

1. **Buy domain:** meshonlabs.in at any registrar (Cloudflare Registrar = at-cost pricing)
2. **Create GitHub org:** github.com → New organization → Free plan → name `meshonlabs`
3. **Deploy the site:**
   ```bash
   cd meshon-labs-site
   git init && git add -A && git commit -m "Meshon Labs landing page"
   git remote add origin https://github.com/meshonlabs/site.git
   git push -u origin main
   ```
   Then: vercel.com → Add New Project → import `meshonlabs/site` → Deploy (zero config, static)
4. **Attach domain:** Vercel → Project → Settings → Domains → add `meshonlabs.in` + `www` → change nameservers / add A-76.76.21.21 + CNAME at registrar per Vercel's prompts → HTTPS is automatic
5. **Email:** Zoho Mail Free or Cloudflare Email Routing → `hello@meshonlabs.in`
6. **LinkedIn company page** + **X handle** — copy below

## 6. Services menu (pricing guidance)

Positioning: full-stack IT services with a multi-domain bench. Quote per project after scoping; the bands below anchor negotiations.

| Engagement | What it covers | Indicative band |
|---|---|---|
| Fixed-scope project | Website / web platform / portal / chatbot with agreed scope and deadline | ₹40k–₹3L+ |
| Dedicated team | Engineer(s) from the bench working only on the client's product, monthly | ₹80k–₹2L+/mo per engineer |
| Care & support plan | Monitoring, maintenance, small improvements on live software | ₹8k–₹25k/mo |
| AI & automation build | Chatbots, document assistants, workflow agents | ₹50k–₹2.5L+ |

*Rule of thumb: price the outcome, not the hours. Split revenue transparently within the team from project one — it keeps the partnership permanent.*
